# Messerschmitt Me-262 A-1a

This document will hold every number that describes the aircraft, with the
source and the confidence mark of each one. The table below repeats the
reference data of `docs/CONVENTIONS.md` section 8. It is the single place to
look up a value. The later sections will add the derived numbers, such as the
inertia tensor and the surface geometry, and will show how each estimate came
about. Do not invent a number that is missing. Estimate it, mark the estimate,
and record the method.
