# Flight model

This document will describe the component based aerodynamic model of the
aircraft. It will list every force and every moment that the model applies. For
each one it will give the frame, the equation, and the source of the numbers. It
will not repeat the reference data, which lives in `docs/aircraft-me262.md`. All
values here use the SI units of `docs/CONVENTIONS.md` section 2, and all body
axis signs follow section 3.
