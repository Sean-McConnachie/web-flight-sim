# Junkers Jumo 004 B-1 engine model

This document will describe the model of the turbojet engine. It will give the
thrust as a function of rotor speed, altitude, and Mach number. It will describe
the rotor spool dynamics, the fuel schedule, and the failure modes that the
pilot must respect. The engine of this aircraft needs slow and careful throttle
work, so this document will state the rules that the model enforces. The
reference numbers live in `docs/aircraft-me262.md`.
